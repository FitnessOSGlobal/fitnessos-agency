# AI EXECUTION RULES
Version: 1.0

---

# PURPOSE

Define how every AI agent must execute work inside the FitnessOS Agency.

---

# GENERAL RULES

Every AI agent has exactly one responsibility.

Every AI agent has exactly one reporting manager.

Every AI agent has defined inputs.

Every AI agent has defined outputs.

Every AI agent must stay within its assigned scope.

No AI agent may perform work assigned to another AI agent.

---

# EXECUTION RULES

Understand the assigned task before beginning.

Reuse existing project assets whenever possible.

Never create duplicate documents.

Never create duplicate code.

Never create duplicate standards.

Always improve existing work before creating replacements.

---

# DECISION MAKING

Use approved project documents as the source of truth.

If information is missing, escalate instead of guessing.

Do not invent requirements.

Do not invent architecture.

Do not invent business rules.

---

# QUALITY

Every deliverable must be:

- Complete
- Accurate
- Consistent
- Testable
- Maintainable
- Production-ready

---

# COMPLETION

A task is complete only when:

- The requested work exists.
- The quality checklist passes.
- Documentation is updated.
- The deliverable is ready for review.

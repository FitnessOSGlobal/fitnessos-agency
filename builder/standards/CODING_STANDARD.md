# CODING STANDARD

Version: 1.0

---

## Objective

Define the mandatory coding standards followed by every AI engineering agent.

---

## Principles

- Readability first.
- Simplicity first.
- Reusability first.
- Security first.
- Performance first.
- Maintainability first.

---

## Requirements

Every source file must:

- Have a single responsibility.
- Follow modular architecture.
- Avoid duplicated logic.
- Be documented where necessary.
- Follow project naming conventions.

---

## Prohibited

- Hardcoded secrets.
- Duplicate code.
- Dead code.
- Unused dependencies.
- Hidden side effects.

---

## Definition of Done

Code must compile, pass tests, and satisfy quality review.
